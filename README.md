# NetCash

A web-based Banking System developed using Django and Python as an academic project at Palawan State University.

The system helps manage borrower information, savings accounts, loan applications, payments, and financial records in one platform.

## Technology Used

- Python
- Django
- SQLite
- HTML, CSS, and JavaScript
- Bootstrap
- ReportLab (PDF generation)
- Git and GitHub


## Features

- User registration and login
- Role-based access
- Borrower profile management
- Identity verification
- Automatic savings account creation
- Savings deposits and withdrawals
- Loan application and approval
- Loan eligibility and risk assessment
- Loan payment and amortization records
- Downloadable loan agreement PDF
- Transaction history, audit logs, and notifications

## User Roles

| Role | Responsibilities |
|---|---|
| **Borrower** | Registers an account, manages personal information, submits loan applications, views savings information, and monitors loan records. |
| **Staff** | Manages borrower records, verifies identities, assists with savings operations, and reviews and processes loan applications. |
| **Admin** | Manages system users and roles and oversees the overall system. |
